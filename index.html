ABSENSI WAJAH SISWA

SMA Negeri 1 Simpang Empat • Kedatangan pagi

Halaman kamera mandiri. Masukkan URL Web App Apps Script pada konfigurasi sebelum digunakan.

Gunakan pencahayaan cukup dan satu wajah saja. Jika tidak dikenali, siswa diarahkan ke petugas untuk absensi alternatif.

Pendaftaran Wajah

Khusus petugas. Pastikan persetujuan dan data siswa sudah tersedia.

Template numerik wajah akan dikirim ke backend sekolah dan disimpan di sheet TemplateWajah.

Petunjuk awal

Aplikasi ini berjalan pada GitHub Pages (bukan di dalam Apps Script), agar browser dapat meminta izin webcam. Backend Google Apps Script tetap menyimpan data ke Google Sheets.
